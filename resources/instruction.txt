---------------
1. St. Tammany Parish Concrete Pros
   https://st-tammany-parish-concrete-pros.vercel.app/
   Source: index.html

2. New Orleans Concrete Pros

Vercel setup (live)
-------------------
Two Vercel projects, same GitHub repo:
  - st-tammany-parish-concrete-pros  → https://st-tammany-parish-concrete-pros.vercel.app/
  - new-orleans-concrete-pros        → https://new-orleans-concrete-pros.vercel.app/

Build: scripts/select-home.js copies the correct homepage into /public
based on VERCEL_PROJECT_PRODUCTION_URL.

Brand switcher uses absolute production URLs so companies always open
on the correct domain.
